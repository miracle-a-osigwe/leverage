System Overview

Leverage balances two distinct computational engines to solve the tension between zero-latency responsiveness and infinite generative reasoning:

  • Deterministic Synthesis Kernel: A mathematical matrix executing sub-millisecond syntactic transformations for real-time slider controls (Firmness × Diplomacy).
  • Google Gemini 2.5 Flash Engine: Client-side structured AI sparring for unscripted adversarial meeting pushback and arbitrary contract clause risk audits.

Architecture & Reference Code Route

1. src/engine/synthesisEngine.ts
The Tactical Kernel: Contains pure mathematical mapping functions that take (rawDraft, firmness, diplomacy, preset) and generate token-level redline diff arrays (strikethroughs vs. insertions) and compute the 0–100 Leverage Index with zero network delay.
2. src/services/geminiService.ts
Generative Intelligence Layer: Connects directly to Google's gemini-2.5-flash endpoint via client-side fetch with structured JSON response schemas for generateCustomObjectionCounters() and auditCustomClause(). Also handles localStorage API key persistence and offline fallback simulation.
3. src/components/DocumentWorkspace.tsx & App.tsx
Reactive Workspace Orchestrator: Manages persona state (Founder vs. Career), preset loading, view switching between Live Redline and Clean Dispatch, and coordinates the collapsible Tactical Debrief drawer.

To Change This, Start Here

  • Add a new scenario preset: Edit src/data/scenarioPresets.ts to define incoming draft text and high-leverage counter-transformations.
  • Tune the negotiation scoring formula: Inspect calculateLeverageScore() in src/engine/synthesisEngine.ts to calibrate posture metrics.
  • Expand contract hazard detection patterns: Add regex checks and curated gotchas in src/data/clausePresets.ts.
  • Adjust AI temperature or prompts: Modify system prompt definitions in src/services/geminiService.ts.

A Reusable Practice: The Dual-Engine Model

Takeaway for Future AI Projects: Never force high-frequency interactive UI controls (like sliders or typing inputs) to wait on an asynchronous LLM request. By building a local deterministic engine for immediate tactile feedback and reserving Google Gemini 2.5 Flash for unscripted adversarial reasoning, the user experience feels instantaneous while remaining intellectually formidable.
