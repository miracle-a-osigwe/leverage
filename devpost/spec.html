Leverage — Technical Specification

The engineering blueprint for building the high-stakes communication, meeting prep, and contract review copilot.
STATUS: DRAFT → READY FOR APPROVAL DOC: SPEC.MD COMPANION STACK: VITE + REACT + TS + TAILWIND

Architecture & 0ms Reactive Data Flow

CLIENT INPUT
Presets & Editor
User selects scenario preset or writes draft. Emits payload into negotiation state hook.
TACTICAL MATRIX
synthesisEngine.ts
0ms phrase-level hazard scanner. Matches passive-aggression, hedging, and concessions.
CALIBRATION BUS
Firmness × Diplomacy
Dual sliders dynamically recalculate semantic substitutions and live Leverage Index.
EDITORIAL OUTPUT
Redline & Dispatch
Renders inline strikethroughs, hazard pills, clean dispatch copy, and tactical rationale.

Component Structure (Tied to PRD)

<TelemetryBar />
Implements PRD > Top Header & Telemetry Bar

Persona toggle (Founder/Employee), tab navigation, Firmness & Diplomacy sliders, and animated circular Leverage Gauge.

<DocumentWorkspace />
Implements PRD > Subtext Equalizer

Controls ViewSwitcher (Redline, Clean, Raw), holds RedlineViewer, PresetSelector, and TacticalDebriefDrawer.

<ObjectionSimulator />
Implements PRD > Objection Simulator

Renders adversarial investor/manager objections and 3 high-conviction counter-frames (Direct Answer, Pivot, High Ground).

<ClauseRadar />
Implements PRD > Clause Radar

Scans contract clauses for gotchas (Red/Amber/Green) and renders 1-click equitable counter-clauses with copy button.

How to Run:

npm install
npm run dev
# Open http://localhost:5173

No external API keys or network dependencies needed. Reviewers and demo recording will run at 100% speed with zero configuration.

  • Client-Side Engine over Remote LLM on Sliders: Avoids 3-5 second network lag and rate limits during live slider movement; delivers 0ms 60fps responsiveness.
  • Preloaded High-Stakes Presets over Multi-Page PDF Parser: Avoids PDF layout bugs and OCR failures, giving evaluators instant gratification in a 60-second video demo.
